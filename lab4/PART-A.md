# Part A — recorded before opening `snake_oop.cpp`

Source used: the repository README on 2026-09-29.

1. Eating food grows the snake and increases the score.
2. In Border Mode, touching a wall ends the game.
3. In No Border Mode, crossing an edge wraps the snake to the opposite edge.
4. Colliding with the snake's own body ends the game.
5. In Hard difficulty, colliding with an obstacle ends the game.
